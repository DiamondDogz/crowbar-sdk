- **A setting for some games only**: an item of `options` can list `titleIds` (among the runtime's own). Crowbar shows it only on those games' settings screens, so a runtime that runs several games can offer a setting that only one of them has. The same `key` may come back for other games. `crowbar-check` checks the ids and warns about one the runtime does not list. See [SPEC.md, settings screen](https://github.com/DiamondDogz/crowbar-sdk/blob/main/SPEC.md#settings-screen-optional-options).
- **An update kept beside the game**: a runtime that never changes the game folder can keep the unpacked update in `{data}/player-content/update/<titleId>/` and apply it at every start. Crowbar reads its `sce_sys/param.sfo` and shows that version as installed in the game's Add-ons. See [SPEC.md §4](https://github.com/DiamondDogz/crowbar-sdk/blob/main/SPEC.md#4-features-dlc-updates-dialogs).

Both need Crowbar 0.2.11. An older Crowbar shows a setting with `titleIds` on every game. Runtimes built with SDK 1.7 need nothing new.
