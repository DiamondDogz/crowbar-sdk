**Unlock on request, for Crowbar's trophy test profile** (optional). A developer can now check the whole trophy chain without playing: Crowbar asks the running game `<n> unlock <id>` in `PS4RT_CONTROL_DIR`, the runtime unlocks it through its own path, as if the game had, and answers `unlocked` or `refused`. In the test profile, `PS4RT_TROPHY_FILE` and `PS4RT_ACHIEVEMENTS_DIR` point to separate files, so real trophies are never touched. See [SPEC.md §4](https://github.com/DiamondDogz/crowbar-sdk/blob/main/SPEC.md#unlock-on-request-crowbars-trophy-test-profile-optional-sdk-13).

- C: `crowbar_poll()` returns `CROWBAR_UNLOCK`, `crowbar_request_trophy()` gives the number, `crowbar_answer(1 or 0)` replies.
- Python: `crowbar.poll()` returns `"unlock"`, `crowbar.request_trophy()` gives the number.
- Nothing changes for pause; a runtime that does not know `unlock` simply never answers it.

pip install git+https://github.com/DiamondDogz/crowbar-sdk@v1.3.0
