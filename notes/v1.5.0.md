Everything here is optional: a runtime that uses none of it keeps working as before.

- **Presence**: a `presence` file in `PS4RT_CONTROL_DIR` (`status=Chapter 3, Imperial Theater`) is shown to the player's friends and on Discord. `crowbar_set_presence()` / `crowbar.set_presence()`.
- **Online play**: `online=1` in the same file and Crowbar never pauses the game, neither by request nor by suspending it.
- **Captures**: `PS4RT_CAPTURE_DIR`, a folder per game for screenshots and clips; Crowbar shows them in the game's Captures. `crowbar_capture_dir()` / `crowbar.capture_dir()`.
- **`minCrowbar`** in `crowbar.json`: the oldest Crowbar version the runtime needs; an older one asks the player to update instead of launching.
- **`mods`** in `crowbar.json`: the folder the runtime reads mods from, with an optional help text; Crowbar shows it in the game's Add-ons.
- `crowbar-check` validates `minCrowbar` and `mods`; the JSON schema knows them.

Needs Crowbar 0.2.9 or later for presence, captures and mods.
