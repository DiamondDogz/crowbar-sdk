**Quit from Crowbar, existing trophy files, game-language variables, button style, and a Windows porting guide.**

- **Quit** (optional): when the player quits from Crowbar's Guide, Crowbar asks `<n> quit` in `PS4RT_CONTROL_DIR`. The runtime saves what it must, answers `quitting` and exits with code 0 within 2 s; otherwise Crowbar closes it, and never reports it as a crash. C: `CROWBAR_QUIT`; Python: `"quit"`.
- **`trophyFile` + `trophyFormat`** in `crowbar.json`: a runtime that already keeps its unlocks in another format says where and how (`sdk`, `ps4rt-unlocks`, `trg-progress`); no second file to write. `*` allowed in the file name and its folder.
- **`language`** in `crowbar.json`: `{"env": "DCP_LANGUAGE", "values": {"1": "english", "2": "french"}}`; Crowbar passes that variable beside `PS4RT_LANGUAGE`.
- **`PS4RT_BUTTON_STYLE`** (`playstation` or `xbox`) passed to every runtime: the button prompts the player wants.
- **[docs/WINDOWS.md](https://github.com/DiamondDogz/crowbar-sdk/blob/main/docs/WINDOWS.md)**: the traps of a Windows port (System V ABI for everything the game calls, POSIX calls, fonts, always-on-top windows, GitHub's MSYS2).
- **`templates/release-windows.yml`**: release or pre-release by version suffix, titled `<launcher> windows-<version>`, safe with GitHub's MSYS2.
- `crowbar-check` validates the new keys; the schema knows them.

pip install git+https://github.com/DiamondDogz/crowbar-sdk@v1.4.0
