- **`crowbar-check --runtime-test --game <dump>`**: starts the runtime the way Crowbar does, with temporary trophy, achievements and capture folders (the player's real ones are never touched), and checks every answer of the exchange against SPEC.md:
  - `0 ready` written, without a blocking dialog;
  - `pause` answered `paused` or `refused` within 300 ms;
  - `resume` answered `running`, process still alive;
  - `unlock <id>` answered within 1.5 s, and the trophy present in `PS4RT_TROPHY_FILE`;
  - `capture <id>` answered, then a PNG saved in `PS4RT_CAPTURE_DIR` (optional);
  - `quit` answered `quitting`, exit code 0 within 2 s.
  `--json` for CI, `--keep` to keep the runtime output. On failure, the folders and the runtime's output are kept and their path printed.
- [docs/VISION.md](../docs/VISION.md): where the SDK and the runtimes are going.

No change to the exchange itself: runtimes built with SDK 1.6 need nothing new.
