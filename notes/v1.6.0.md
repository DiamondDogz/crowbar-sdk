- **Screenshot on a trophy**: with the player's new setting on, Crowbar asks the running game for a picture when a trophy unlocks (`<n> capture <id>`). The runtime answers `capturing` and saves its next game frame, without overlays, as `trophy-<id>-<n>.png` in `PS4RT_CAPTURE_DIR`. Crowbar shows it on that trophy and in the game's Captures. Without an answer, Crowbar takes the screen itself on Windows.
- C: `CROWBAR_CAPTURE`, `crowbar_capture_name()`. Python: `poll()` returns `"capture"`, `capture_path()`.

Optional, like everything in the exchange: a runtime that ignores `capture` keeps working.
